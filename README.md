# GoldSpectra AI

منصة SaaS متقدمة لتحليل مؤشرات التحول الحراري المائي المرتبطة بالذهب.

## الميزات

- تحليل طيفي متعدد المستشعرات (ASTER, Sentinel-2, EMIT, EnMAP, PRISMA)
- نموذج Prospectivity Mapping هجين
- خرائط Relative Mineral Abundance + Uncertainty
- Sensor Agreement Score
- تقارير متوافقة مع روح معايير JORC / NI 43-101
- واجهة عربية RTL + إنجليزية
- خطط Free / Pro / Enterprise

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## إخلاء المسؤولية

الأداة تُحسّن ترتيب الأهداف ولا تؤكد تواجد الذهب. التحقق الميداني والتحاليل الجيوكيميائية ضروريان دائماً.
